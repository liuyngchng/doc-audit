# 文档审核 使用说明

文档审核把在线文档或本地文档按模板重新排版，输出格式规范的 Word 文档。模板可以自己设计，也可以从一份排好的 Word 里自动提取；另附「Doc格式转换」，把老版 `.doc` 批量转成 `.docx`。

---

## 一、功能一览

| 功能 | 能做什么 |
| --- | --- |
| 文档排版 | 在线文档链接或本地文件 → 选定模板 → 规范 Word；任务可并行，历史可回看、可重转 |
| 模板集 | 一套输出方案 = 多份文档模板，一次生成会议记录、决议、通报等多类文档 |
| 模板设计 | A4 版面预览，点哪个元素就改哪个元素 |
| 从 Word 导入模板 | 从一份排版规范的 `.docx` 自动提取字体、字号、对齐、行距、缩进、页边距、页码与页眉页脚 |
| Doc格式转换 | 老版 `.doc` 批量另存为 `.docx`，产物落在源文件旁边 |
| 模型服务 | 登录后默认启用内置服务；也可以在「设置」里接自己的模型服务 |

---

## 二、开始使用

解压到任意文件夹，双击 **doc-audit**（关闭窗口即退出，重复双击不会多开；首次运行如被 Windows 拦截，点「仍要运行」）。

点左侧栏底部 **「登录」**，在打开的页面里授权（或扫码），约 30 天内免登录。登录后默认启用内置模型服务（限公司员工），新建任务页会出现在线文档链接输入框。

---

## 三、文档排版

三步：**选来源 → 选模板 → 开始转换**。

- **来源**：粘贴在线文档链接（需已登录），或把本地文件拖进上传区。本地支持 docx / doc / txt / md，以及在线文档源快照 json。
- **模板**：选模板集，再选其中的一份模板。
- **格式处理选项**：三组开关 —— 段落结构（是否识别段首标题句）、保留原文文字格式（加粗、斜体、下划线、删除线、字体颜色、底色高亮、字符间距、字符缩放，默认只保留加粗）、内容处理（内容校对、人员姓名校对）。
- **并行与历史**：转换中可继续新建任务，旧任务不中断；左侧「文档排版」按文档记录历史，点开可回看或重转（同一文档自动更新，不重复堆积）。

---

## 四、模板集

模板集就是一套输出方案：一次转换可以按里面的多份文档模板，同时生成多类文档（如会议记录、会议决议、会议通报）。每份文档模板可以单独设置：

| 设置项 | 说明 |
| --- | --- |
| 段落样式内容 | 生成时保留哪些元素。例如「会议决议」只保留标题和一级标题，其余不输出 |
| 元素格式 | 各元素的字体、字号、对齐、行距、缩进、加粗、颜色 |
| 页面设置 | 页边距、页码等 |

**常用操作**

- **新建**：点「新建模板集」，再「＋ 添加文档」
- **加载**：点左侧模板集列表中的某一项
- **保存**：改完点「保存模板集」
- **删除文档模板**：点文档标签上的 ×

程序自带一份「默认模板集」可直接使用；自己新建的模板集可以分享给同事使用。

---

## 五、模板设计

在「模板设计」页签，预览区模拟 A4 纸张效果，**点击任意元素**（标题、副标题、各级标题、正文、页码等），在右侧面板修改格式：

| 可调整项 | 说明 |
| --- | --- |
| 字体、字号 | 下拉选择，字号用中文字号（如三号、小四） |
| 对齐 | 居中 / 两端对齐 / 左对齐 / 右对齐 |
| 行距、段前段后 | 控制行与行、段与段的间距 |
| 首行缩进 | 如填 2 表示首行空两格 |
| 加粗、颜色 | 开关和调色板 |
| 页面边距 | 上下左右边距，按厘米设置 |

---

## 六、从 Word 导入模板

手上有一份排版规范的 Word 文档，可以直接导入生成模板：程序自动识别各类元素的字体、字号、对齐、行距、缩进、页边距、页码，以及页眉页脚（含图片 logo、页号样式、奇偶页/首页不同）；在识别结果里逐段确认（判错的段落改归到正确的样式，不需要的取消勾选）后，作为一份文档模板加入模板集保存即可复用。

> 识别依据是整篇文档中出现最多的格式，个别段落识别不准很正常，手动调整一下即可。

---

## 七、Doc格式转换

把老版 `.doc` 批量另存为 `.docx`：产物落在**源文件所在目录**，文件名不变、只换扩展名，保存效果等同在 Word 里手动「另存为」。

- **来源**：点「来源」框选一个文件夹（默认含子文件夹），或把 `.doc` 文件直接拖进框里只转这几个。
- **结果**：逐条列出每个文件的结果（OK / SKIP / FAIL）；**点记录里的文件名直接打开该文件**，源文件散在不同子目录时也一眼看得出在哪一层；同名 `.docx` 默认跳过，勾「覆盖」才重做。
- **清理**：转换完点「删除 .doc 文档」，把已生成 `.docx` 的源 `.doc` 移到**回收站**（跳过与失败的不动，需要可从回收站还原）。
- **边界**：只处理 `.doc`；一次最多 200 个文件，更多请用文件夹模式。
- 转换由本机 Word 完成 ⇒ 需要装 Word，且**开始前关掉所有 Word 窗口**：转换会接管 Word 并在收尾退出，未保存的内容会丢。

> 同一个工具也放在安装目录的 `tools\doc2docx.bat`：把文件夹拖到它上面即可，或在命令行里
> `doc2docx.bat "D:\公文\2026" -Recurse -Force`。
